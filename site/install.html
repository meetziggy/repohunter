Install RepoHunter

Pick your agent. Every command is pinned to the v0.2.1 release, so nothing on the main branch reaches you unreviewed. Needs uv; Python standard library only; your GitHub token never leaves your machine.

Open in CursorOne click; your client asks you to confirm. Or paste the config below.
claude mcp add repohunter -- uvx --from git+https://github.com/meetziggy/repohunter@v0.2.1 repohunter-mcp
Your agent can now check what exists before it builds or installs.

Every way to install

Claude Code plugin

The MCP server plus the skill that tells your agent when to use it. Paste into Claude Code.

Claude Code
/plugin marketplace add meetziggy/repohunter
/plugin install repohunter

Any MCP client

Claude Desktop, Windsurf, Zed, Cline and others: add this to the client's MCP config.

Where each client keeps its config
mcp.json
{
  "mcpServers": {
    "repohunter": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/meetziggy/repohunter@v0.2.1", "repohunter-mcp"]
    }
  }
}

CLI

Runs once with no install. Swap in any owner/repo or GitHub URL.

README
Terminal
uvx --from git+https://github.com/meetziggy/repohunter@v0.2.1 repohunter scan rtk-ai/rtk

Keep the command

Installs repohunter and repohunter-mcp on your PATH.

Terminal
uv tool install git+https://github.com/meetziggy/repohunter@v0.2.1
repohunter evaluate rtk-ai/rtk

Check every install path yourself: python3 scripts/verify_install.py in a clone runs each one in a throwaway sandbox.
